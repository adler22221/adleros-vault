# Q7 — 志望動機・意気込み（1000文字以内）

IGNITEが求めているのは、学生の挑戦に伴走し、地道な運営も担い、その実践ごと長く育てられる人だと理解しています。

十八歳未満の若者十六名に、五年以上かけて個別に伴走してきました。うち七名は困難を抱えた家庭の出身です。統一入学試験を経ずに大学へ進んだ者、学士を持たないまま大学院に進んだ者、国際的な教育賞を受けた者、自分の組織を立ち上げた者がいます。システム思考の講座では、受講生の一人がMap the System 2022の台湾代表として、オックスフォード大学での世界大会に出ています。追跡すると、三割以上が社会的インパクトの領域に、七割五分以上が人文社会科学系の進路に残っていました。

しかし、個人への伴走だけでは足りないと気づき、高等教育と知の生産の場そのものを問い直すようになりました。ミネルヴァ大学やThiel Fellowshipに接し、民主的・生態的な大学の代替案を各国に訪ねています。

同時に、組織と組織のあいだをつなぐ仕事も重ねてきました。ZA Shareの研究・国際部門ディレクター、コンラート・アデナウアー財団KASpaces台湾のプログラムディレクター兼主任研究員として、官・民・学・NPOをつなぐ協働を設計してきました。火を点けるだけでなく、火と火をつなぐこと。それが私の仕事でした。

貢献できる筋は三つあります。第一に、学生チームへの伴走です。問いの立て方、関係者との接続、試作と振り返りを一緒に回します。第二に、参加型の場を設計し、その運営を自分で担うことです。設計と実施を切り離さないのは、謙遜ではなく方法上の判断です。なぜならば、実施を手放した瞬間に、設計は本来やろうとしたことから切れてしまうからです。第三に、実践を仕組みと知に戻すことです。メンタリングや運営そのものを研究の対象にし、次に残る方法へ変えていきます。

ただし、何かを持ち込む前に、まず学びたいと考えています。七年かけて積み上げられてきたものを、守破離の「守」から受け取ることから始めます。まず三か月、互いに見極めたうえで、五年以上の関わりを想定しています。ライフワークを続けながら関わるハーフコミットを希望します。教育に従事しながら、その教育を研究の対象とする役割も担う用意があります。

自分が抜けたあとも回り続ける仕組みを残すこと。そこまで含めて引き受けたいと考えています。
